A

The packet — what one frame carries

1728 bits · 864 dibits · one frame
Frame sync
48 bits
0x5575F5FF77FF
A fixed marker — "a frame starts here." Every frame opens with it, 864 dibits apart.
NID — network ID
64 bits
NAC + DUID
BCH-protected. NAC = which system (12-bit). DUID = what kind of frame (4-bit).
Payload
Data or voice blocks
+ status symbol every 36th dibit
FEC-coded and interleaved. For GPS it's a data PDU; for talk it's the IMBE voice of an LDU. The status symbols are housekeeping woven through — stripped before decoding.
C4FM: 4 signal levels · 4800 symbols/sec · 2 bits per symbol (a "dibit")
B

The breakdown — peeling off each layer

the common path, every frame

1 · Detector audio

The radio FM-detects the signal to a flat 4-level C4FM baseband (or an SDR's IQ → FM-detect). The hard RF work is already done — we only ever receive.

2 · Recover symbols

An MMSE tracking loop locks the clock and level and slices the baseband into 4 levels → dibits (2 bits each), 4800 a second.

3 · Lock the frame

Scan the dibit stream for the sync word 0x5575F5FF77FF. It marks the start of every 1728-bit frame and aligns everything after it.

4 · Read the NID

BCH-decode the 64-bit NID → NAC (which system) and DUID (which frame type). The DUID decides what happens next.

The DUID forks the frame — data goes to the map, voice goes to the vocoder ↓
